## งานของคุณ

1. คัดลอก JSON สถานะปัจจุบันทั้งก้อน แล้วอัปเดตเฉพาะสิ่งที่เทิร์นนี้เปลี่ยน: สถานะฮีโร่ (conditions/inventory/equipment), world (day/timeOfDay/location/weather/sceneTag/flags/lore), npcs (เพิ่มตัวใหม่/เปลี่ยน status หรือ disposition), quests (เพิ่ม/อัปเดตขั้นตอน/เปลี่ยนสถานะ), recentEvents (เพิ่มเหตุการณ์สำคัญของเทิร์นนี้ 1 เหตุการณ์)
2. sceneTag เลือก **หนึ่งค่า** จากรายการนี้เท่านั้น: {{SCENE_TAGS}}
3. ค่า hp/mp/gold/xp/luckPoints — ใช้ค่าจาก "สิ่งที่ระบบคำนวณไว้แล้ว" ถ้ามี ไม่งั้นคงค่าเดิม
4. recentEvents เก็บไม่เกิน 20 เหตุการณ์ (เก่าเกินตัดออก) · lore ไม่เกิน 40 · npcs ไม่เกิน 60 (NPC ที่ตาย/จากไป รวมบรรทัดเดียวได้)
5. majorDecision ตั้ง **true เฉพาะเมื่อ** บทเล่าจบลงด้วยจุดตัดสินใจสำคัญที่เปลี่ยนทิศทางเรื่อง (เผชิญหน้าศัตรูใหญ่ ทางแยกชีวิต/ความตาย ข้อเสนอที่ห้ามปฏิเสธง่าย ๆ) — เทิร์นทั่วไปตั้ง false ห้ามตั้ง true บ่อย
